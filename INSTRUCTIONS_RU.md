# Как открыть и сдать

1. Распакуй ZIP целиком. Открой папку maze-escape, где находятся src и README.md.
2. В IntelliJ: File → Open → выбери maze-escape. Выбери JDK 17 или новее.
3. Открой Terminal внизу IntelliJ. Введи по очереди, после каждой команды Enter:

```powershell
java tools/Check.java
java -cp out Main
```

Первая команда компилирует и проверяет три чужих примера. Вторая возвращает
твою картинку: 9 строк, 10 столбцов, ID 252223. Поэтому после Check всегда запускай Main.
Не запускай MakeVariant с другим ID и не заменяй входные данные.

4. В проводнике открой output → maze.html двойным щелчком.
Сними zones и slides для обычного вида. way out показывает красный путь.
Управление стрелками. PNG — статичная картинка; HTML — интерактивная страница.
Разноцветные 90 зон здесь корректны: Zones=90, Largest zone=1, Is DAG=1.
5. Прочитай DEFENSE_RU.md, разбери исходники и адаптируй работу перед сдачей.
Задание запрещает сдавать неизменённую AI-работу; раздел AI use заполнен честно.
Измени формулировки отчёта своими словами и внеси осмысленные собственные изменения.

## GitHub

В ZIP включена скрытая папка .git с последовательными коммитами текущей сборки.
Не удаляй её. Коммиты подписаны помощником, а не выданы за твою самостоятельную работу.
Проверь историю:

```powershell
git log --oneline
git status
```

На GitHub нажми + → New repository → имя maze-escape → Public.
Не добавляй README, .gitignore или license: они уже есть в проекте.
Нажми Create repository. После собственного разбора и правок:

```powershell
git add .
git commit -m "Review and adapt maze implementation"
git remote add origin https://github.com/AbishevAssylzhan/maze-escape.git
git push -u origin main
```

Адрес выше подходит, если ты создал именно maze-escape в своём аккаунте.
Если репозиторий назван иначе, скопируй фактический URL с GitHub.
Если git просит имя/email, настрой свои данные для будущих коммитов.
После push открой репозиторий в окне инкогнито и проверь README, data и output/maze.png.
В Moodle отправляется ссылка на публичный репозиторий, не только ZIP.
