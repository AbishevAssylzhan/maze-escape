# Подготовка к защите: 5 минут

## Суть проекта
Клетка — вершина графа. Внутренняя стена — ребро между соседними клетками.
Mission 1 удаляет стены по порядку файла, если они соединяют разные компоненты.
Получается дерево. Mission 2 отдельно ищет самое дешёвое дерево.
Slides — другой, направленный граф: они игнорируют стены.

## Где что написано
- DisjointSet.java: parent хранит родителя, size — размер дерева, sets — число компонент.
  find сначала находит корень, потом сжимает весь пройденный путь.
  union прикрепляет меньшее дерево к большему. Если корни равны, возвращает false.
- Maze.breakWalls: проходит стены в исходном порядке. Успешный union означает сломанную стену.
- Maze.cheapestMaze: сортирует индексы стен по стоимости, затем применяет DSU.
- Maze.primCost: начинает с клетки 0, берёт минимум из PriorityQueue.
  Рёбра, ведущие в уже посещённую вершину, пропускаются.
- Escape.escape: явный стек и индекс следующего направления имитируют рекурсивный DFS.
  parent нужен для восстановления пути. visited увеличивается при первом посещении.
  Выход завершает поиск; тупики считаются отдельно по всему графу.
- Zones.kosaraju: первый обход исходного графа записывает вершины при выходе.
  Второй идёт по убыванию времени выхода в обратном графе, выдавая номера SCC.
- Zones.routes: HashMap сохраняет минимум для каждой пары зон. Далее два DP:
  stages[b] = max(stages[b], stages[a]+1);
  distance[b] = min(distance[b], distance[a]+cost), только если a достижима.

## Частые вопросы
**Почему нельзя просто удалить самые дешёвые n-1 стен?**
Они могут создать цикл и оставить часть клеток изолированной. DSU предотвращает цикл.

**Почему Kruskal и Prim дают одинаковое число?**
Оба строят MST. При различных весах MST единственно, хотя порядок выбора может отличаться.

**Почему DFS-путь единственный?**
Граф — дерево. Два разных простых пути создали бы цикл.

**Почему не рекурсия?**
Большая глубина вызывает StackOverflowError. Массив-стек лежит в heap.
Простое добавление всех соседей в стек может изменить момент посещения;
здесь кадр хранит следующее направление, как рекурсивный DFS.

**Что такое SCC?**
Максимальный набор вершин, где каждая достижима из каждой по направленным рёбрам.

**Почему граф SCC всегда DAG?**
Цикл из нескольких SCC означал бы взаимную достижимость: это была бы одна SCC.

**Почему нет Dijkstra в Mission 5?**
Готов топологический порядок. Все предшественники обработаны раньше,
достаточно одного прохода по рёбрам; очередь с приоритетом не нужна.

**Почему long для стоимости?**
Сумма большого количества int-весов может выйти за диапазон int.

**Сложности?**
DSU: O(alpha(n)) амортизированно. Kruskal: O(m log m).
Prim: O(m log m) с этой очередью рёбер. DFS/Kosaraju: O(n+m).
Проход по графу зон: O(K+E).

## Мини-задачи для самостоятельной проверки
1. Поменяй порядок соседей DFS и объясни, почему visited может измениться,
   а единственный путь остаётся прежним. Перед сдачей верни up/right/down/left.
2. Добавь тест для DSU из одной клетки: count=1, union(0,0)=false.
3. В tiny-примере объясни вручную SCC {0,1}, {2}, {3} и стоимость 4+5=9.
4. Найди место, где параллельные слайды объединяются по минимуму.
