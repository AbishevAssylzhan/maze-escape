# Кратко к защите

- **DSU:** find находит корень; union объединяет компоненты. Используются сжатие пути и объединение по размеру.
- **Mission 1:** ломаем стену, если union возвращает true. Получается дерево: 89 сломанных стен, 72 оставшихся.
- **Kruskal:** сортировка стен по цене + DSU.
- **Prim:** растим дерево, выбирая минимальное подходящее ребро из PriorityQueue.
- **MST:** оба алгоритма дают 26896.
- **DFS:** направления вверх, вправо, вниз, влево. Явный стек защищает от StackOverflowError.
- **Путь:** 19 ходов; DFS посетил 64 клетки, потому что заходил в ответвления.
- **Тупики:** клетки с одним открытым соседом; всего 30.
- **SCC:** вершины, взаимно достижимые по направленным рёбрам.
- **Kosaraju:** обход исходного графа → порядок завершения → обход обратного графа.
- **Зоны:** 90 одиночных SCC, поэтому Is DAG = 1.
- **Flow stages:** самая длинная цепочка содержит 15 зон.
- **Fastest route:** стоимость 29. Внутри зоны перемещение бесплатно.
- **DP:** идём по топологическому порядку зон; очередь с приоритетом не нужна.
- **Сложности:** DSU — O(alpha(n)); MST — O(m log m); DFS/Kosaraju — O(n+m); DP — O(K+E).
- **long:** нужен, чтобы сумма стоимостей не переполнила int.

Файлы: DisjointSet.java, Maze.java, Escape.java, Zones.java.
